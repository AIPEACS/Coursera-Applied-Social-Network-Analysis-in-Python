# Coursera Applied Social Network Analysis in Python

Each numbered directory contains the untouched course notebook at `template/assignmentN.ipynb`, the completed notebook at `assignmentN.ipynb`, and the course assets needed to run it.

The `submission.zip` release asset contains only the four completed notebooks. Upload each notebook to its corresponding Coursera Jupyter lab. The GitHub release is named `submission`; when replacing answers later, replace that release asset in place.
